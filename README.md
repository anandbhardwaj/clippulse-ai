# ClipPulse AI 🎬⚡

ClipPulse AI extracts semantic video segments from YouTube and Instagram URLs. It transcribes audio via Whisper Large v3, finds requested topics via LLM reasoning, and generates a bounded, looping HTML5 preview player.

---

## 🛠️ System Prerequisites

- **FFmpeg** must be installed on your operating system.
  - macOS: brew install ffmpeg
  - Ubuntu/Debian: sudo apt update && sudo apt install -y ffmpeg
  - Windows: winget install Gyan.FFmpeg
